EEP 夾爪 — 即時儀表板

獨立展示頁面，資料直接來自 USB 連接的 ESP32-S3（eep_gripper_h1.ino），不經過、不影響評分用的離線 SPA(src/)
此瀏覽器不支援 Web Serial API。
請改用 Chrome 或 Edge，並確認這個頁面是透過 http://localhost（本機伺服器）開啟，不要用 file:// 雙擊開啟—— Web Serial 需要 secure context，file:// 不保證可用。
在 hardware/tinyml/live-dashboard/ 目錄下執行：python -m http.server 8081， 再開 http://localhost:8081。
