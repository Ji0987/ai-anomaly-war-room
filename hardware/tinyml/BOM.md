# 硬體清單(BOM)

> 開發板已確認型號:[ATK-DNESP32S3M-MiniBoard](https://github.com/openedv/ATK-DNESP32S3M-MiniBoard)(正點原子)。下面的接腳資訊是針對**這塊板子**核實過的,換板子要重查。

## 開發板本身

| 項目 | 規格 | 來源 |
|---|---|---|
| 主控模組 | ATK-MWS3S(ESP32-S3R8,N16R8:16MB Flash + 8MB PSRAM,Octal 模式) | 板子絲印、[官方 repo](https://github.com/openedv/ATK-DNESP32S3M-MiniBoard) |
| Arduino IDE 板子選項 | **ESP32S3 Dev Module** | 官方文件截圖確認,與板子無關,是通用 ESP32-S3 選項 |
| USB 燒錄埠 | 標示「USB SERIAL」的那個 micro-USB 埠(經 CH34x USB 轉序列晶片) | 板子官方標註圖 |
| USB 原生埠 | 標示「USB SLAVE」的另一個 micro-USB 埠,**不要拿來燒錄**,那是 S3 原生 USB,行為不同(需另外開 USB CDC on Boot 才能當序列埠用) | 同上 |
| I2C 預設腳位 | **SDA = GPIO8,SCL = GPIO9** | 官方標註圖確認兩者皆有接出到排針,且與 arduino-esp32 核心的 ESP32-S3 Dev Module I2C 預設值一致;韌體已寫死這兩個腳位 |
| 邏輯電位 | 3.3V(排針上有獨立 3V3 輸出接點) | 板子標註圖 |
| 供電 | USB 或排針上的 5V/3V3 輸入 | 板子標註圖 |
| USB 驅動 | 若電腦找不到 COM 埠,安裝 CH340 或 CH343 USB 轉序列驅動(官方文件與板子圖片對這顆晶片型號標示不完全一致,兩種驅動都可以先試) | 官方 repo README + 板子圖片 |

**特別提醒**:N16R8 模組用 Octal PSRAM,GPIO35-37 因此**不可用**(官方文件明確提到);目前的 H0 韌體沒有用到那三根腳,不受影響,但之後如果要加更多感測器,避開這三根。

## H0(振動)已有的零件

| 零件 | 狀態 | 備註 |
|---|---|---|
| ESP32-S3 開發板 | ✅ 已有 | ATK-DNESP32S3M-MiniBoard |
| GY-91(MPU9250/MPU6500 九軸,只用加速度計) | ✅ 已有 | I2C 位址 0x68,接 GPIO8(SDA)/GPIO9(SCL) |
| TT 減速馬達 ×4(來自機械手臂車套件) | ✅ 已有 | 只需要用其中 1-2 顆 |
| L298P 雙 H 橋驅動板 | ✅ 已有 | 獨立供電驅動馬達,不要用 ESP32 的 3.3V/5V 直接驅動馬達 |
| MG90S 舵機 ×4 | ✅ 已有 | 用於後續「異常注入」機構(對轉動的馬達施加可重複的摩擦負載) |
| 18650 電池盒(2 節,7.4V) | ✅ 已有 | 供 L298P/馬達獨立供電 |

## 之後方案(聲音/電流/溫度)會用到、目前狀態

| 零件 | 狀態 | 備註 |
|---|---|---|
| INMP441(I2S MEMS 麥克風) | ✅ 已有 | 方案 B(聲音)才會用到,H0 用不到 |
| MAX98357(I2S Class-D 放大器) | ✅ 已有 | 純展示用(異常確診時嗶聲警示),不是感測輸入;3Ω 喇叭低於資料表建議的 4Ω 下限,用低音量短促警示音即可,不要長時間大音量播放 |
| 3Ω/8W 喇叭 | ✅ 已有 | 同上 |
| DS18B20(TO-92 封裝) | ✅ 已有 | 若後續要做溫度感測,貼上馬達外殼時記得用熱熔膠/熱縮套做應力消除,馬達振動會讓細腳位疲勞斷裂 |
| **ACS712-5A**(電流感測) | ⬜ **建議採購** | 5A 版本靈敏度 185mV/A,對應 TT 馬達實際電流範圍(空載 150-250mA、加負載後估計 500mA-1A)解析度最好;**不要買 20A/30A 版本**,靈敏度太粗 |

## H0 不需要,但之後可能需要補的通用材料

- 麵包板、杜邦線(公對母、母對母)——使用者確認電子實驗器材已齊全,這裡只是提醒接線用量會比預期多(GY-91 4 條 + L298P/馬達 4-6 條 + 之後 ACS712 3 條)
- 熱熔膠槍或熱縮套組——固定 GY-91 到馬達外殼、DS18B20 應力消除都會用到
- 小型偏心配重或摩擦片——製造可重複的「負載」異常,原設計建議用 MG90S 驅動一個簡易機構對馬達/輪子施加接觸摩擦,細節見 `NEXT-SESSION.md`
- USB 線——確認是 micro-USB(不是 USB-C),接「USB SERIAL」那個埠

## 明確不用買的東西

- OV5640 相機——已確認排除,不進 TinyML 主線
- ESP-DSP、TensorFlow Lite Micro 這類函式庫——H0 用不到,見 `NEXT-SESSION.md` 的模型選擇建議(決策樹優先,不需要這些重量級工具)
