## 元件選型:找 Codex 獨立覆核後的調整

使用者問「目前元件是最合適的選擇嗎」,找 Codex(GPT-5.6 Sol)獨立覆核並上網查證(討論記錄見 `.agent-bridge` 信箱 MSG 30-31)。三個問題,結論不同,不是照單全收:

| 提案 | 結論 | 關鍵理由(有查證數字) |
|---|---|---|
| TT 馬達改買帶編碼器版 | **採用** | 免費附贈 RPM,呼應先前擱置的轉速需求;A/B 相是數位 GPIO 不走 I2C,不衝突;ESP32-S3 硬體 PCNT 週邊很適合直接解碼 |
| L298N 改 TB6612FNG | **採用,但有前提** | L298 資料表:1A 時 H 橋總壓降最大 3.2V;TB6612FNG 同電流僅 0.5-0.7V,效率 90%+ 對 40-70%,在 6V 系統差異巨大。**但**商品頁常寫的「3.2A」是短脈衝峰值,建議連續額定只有 1.0A/channel——**買之前要先實測 TT 馬達 6V 堵轉電流**,超過就要改 DRV8833(有硬體限流) |
| ACS712 改 INA219 | **不採用,維持 ACS712** | Codex 抓到我沒想到的架構問題:兩顆馬達共用一塊驅動板電源時,INA219 接在總電源處只能量到「兩顆馬達合計電流」,分不出目標馬達自己的;ACS712 可以直接串在目標馬達單一輸出線獨立量測。ACS712 的 80kHz 類比頻寬也遠高於 INA219,若之後想把電流波形細節也當特徵,ACS712 有優勢 |

### 馬達接線腳位對應(6 線,PH2.0 接頭)

比照 D3 套件文件的同款編碼馬達腳位定義(實際顏色以你手上這批為準,務必對照馬達本體上編碼器板的絲印 `M+/M-/VCC/GND/A/B`,不要只憑線色):

| 功能 | 接去哪裡 |
|---|---|
| M+、M-(馬達電源,2 條) | TB6612FNG 馬達輸出端(**不可**接 ESP32-S3 GPIO) |
| VCC(編碼器供電) | 先試接 ESP32-S3 **3.3V**(見下方電位驗證) |
| GND | 與 ESP32-S3、TB6612FNG、電源共地 |
| A 相、B 相 | ESP32-S3 GPIO(避開 GPIO8/9、GPIO35-37),建議用支援硬體 PCNT 的腳位 |

**編碼器 VCC 電位驗證步驟(買線之後、正式接線之前先做)**:
1. 先接 **3.3V** 試看看 A/B 相輸出是否正常(轉動馬達軸,用序列埠印出計數值變化,或示波器/邏輯分析儀看方波)。多數這類霍爾編碼晶片支援 3.3-5.5V 寬電壓,3.3V 若能正常動作,訊號就會安全落在 0-3.3V,可直接接 GPIO,最簡單。
2. 若 3.3V 下無訊號或訊號不穩,才改接 **5V**,並在 A、B 兩條訊號線各加一個簡單分壓電阻(或現成邏輯電位轉換模組)再接 ESP32-S3,不要讓 5V 方波直接進 GPIO(超過 3.6V 絕對上限有燒毀風險)。

## 治具與耗材(不算正式採購,但方案 C 要用到)

- **負載注入機構**:橡皮擦、氈布、小塊海綿或矽膠墊——固定在 MG90S 舵機臂上,轉動時壓向目標馬達軸或外殼,五金行/文具店找,幾乎免費
- **麥克風固定治具**:INMP441 跟目標馬達的距離、角度要跨 run 保持一致(方案 B/C 的前提),用小夾具、3D 列印支架,或簡單用熱熔膠固定在量好距離的位置都可以,重點是**每次錄音距離一樣**
- **GY-91 固定**:熱熔膠直接黏在目標馬達外殼上
- **底板**:方案 C 是目標馬達+干擾馬達+舵機+IMU+麥克風的固定測試台,建議找一塊木板/壓克力板/厚紙板當底座統一固定,不要各元件散接在桌上(位置跑掉會讓資料不可比)
- **接線**:杜邦線,你已確認器材齊全,但方案 C 接線量會明顯變多(2 顆馬達 4 條 + 1 舵機 3 條 + GY-91 4 條 + INMP441 6 條 + ACS712 3 條),建議先點清楚庫存夠不夠

## 轉速感測:已經解決,不用額外採購

先前列在「優先度最低、還沒排進待辦」的轉速(RPM)需求,現在**改買帶編碼器版 TT 馬達後已經免費附贈**,不需要再另外買霍爾感測器+磁鐵或反射式紅外線模組。編碼器 A/B 相用 ESP32-S3 的硬體 PCNT 週邊解碼,不佔用 I2C。

## 明確不用買的東西

- OV5640 相機——已確認排除,不進 TinyML 主線
- ESP-DSP、TensorFlow Lite Micro 這類函式庫——模型選擇建議見 `NEXT-SESSION.md`(決策樹優先,用不到這些重量級工具)
- 機械手臂車套件的任何零件——已決定不拆機,上面所有動力/驅動類都是全新採購
- **溫度感測(DS18B20)——已決定取消,不進任何方案**。原規劃貼在 TT 馬達外殼量溫,但 TT 馬達塑膠外殼確認黏死無法拆解(熱傳導率~0.2-0.3 W/m·K,貼在外殼上量到的會是嚴重衰減延遲的溫度,不是真實繞組溫度),曾考慮改買金屬齒輪箱的 N20 馬達當獨立溫度展示馬達(找 Codex 在蝦皮查證過,齒輪箱高機率為金屬、6-pin 編碼器接頭疑似 JST ZH1.5 但未確認),但賣家未標示快速到貨,時程風險不划算,使用者 2026-08-15 決定放棄,DS18B20(已有現貨)不用於本專題。方案 C 的模態組合維持振動+聲音+電流三項
